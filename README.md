# Air Korea for Home Assistant

공공데이터포털의 **한국환경공단 에어코리아 대기오염정보** API를 사용하는
Home Assistant 사용자 지정 통합입니다.

## HACS 설치

1. HACS에서 **사용자 지정 저장소**를 추가합니다.
2. 유형은 `Integration`, 저장소는 `swallow77/air-korea-ha`로 지정합니다.
3. 에어 코리아 통합을 설치한 뒤 Home Assistant를 재시작합니다.
4. 설정 → 기기 및 서비스 → 통합 추가 → **에어 코리아 (swallow77 개선판)**에서
   공공데이터포털의 일반 인증키(Decoding)와 측정소 이름을 입력합니다.

서비스키는 해당 API에 활용신청 및 승인이 완료된 키여야 합니다. 유효하지 않은
키는 로그에 공공데이터포털 오류 코드와 함께 표시됩니다.

## 1.1.5

- 설정 화면에 최신 OpenAPI 신청 가이드 다운로드 링크 추가
